# Solstice Research — Prompt Appendix Release Desk

Quarterly prompt appendix releases for the Solstice Research evaluation
programme.

## Layout

- `reading-list/q4-2026.json` — the quarter's card manifest: the prompt cards
  to document and the source papers for the bibliography.
- `releases/` — published release bundles, one directory per release id.

Publish the current bundle under `releases/<release-id>/` on the default branch.
